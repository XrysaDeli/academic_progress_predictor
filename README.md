# Academic Progress Predictor

Διαδραστική εφαρμογή Streamlit για την εκτίμηση:

- του τελικού βαθμού πτυχίου και
- της συνολικής διάρκειας φοίτησης.

Η εφαρμογή δημιουργήθηκε στο πλαίσιο διπλωματικής εργασίας και χρησιμοποιεί
μοντέλα μηχανικής μάθησης που έχουν εκπαιδευτεί σε ανωνυμοποιημένα ακαδημαϊκά
δεδομένα. Ο χρήστης συμπληρώνει ή φορτώνει την έως τώρα ακαδημαϊκή του πρόοδο
και λαμβάνει τις αντίστοιχες εκτιμήσεις.

## Εκτέλεση τοπικά

Απαιτείται Python 3.12 και οι βιβλιοθήκες του `requirements.txt`.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Βασικά αρχεία

- `app.py`: κώδικας της εφαρμογής.
- `final_grade_model_401.joblib`: τελικό μοντέλο πρόβλεψης βαθμού.
- `final_duration_model_401.joblib`: τελικό μοντέλο πρόβλεψης διάρκειας και
  κανόνας χρονικής συνέπειας/αργής προόδου.
- `.streamlit/config.toml`: ρυθμίσεις εμφάνισης της εφαρμογής.

## Αποποίηση ευθύνης

Οι προβλέψεις αποτελούν στατιστικές εκτιμήσεις και δεν εγγυώνται το τελικό
ακαδημαϊκό αποτέλεσμα. Δεν υποκαθιστούν επίσημη ακαδημαϊκή ενημέρωση ή
συμβουλευτική.

Το repository δεν περιλαμβάνει τα δεδομένα εκπαίδευσης ούτε προσωπικά δεδομένα
φοιτητών.
